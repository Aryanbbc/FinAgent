# Portfolio summary

FinAgent V1.0.0 is a full-stack, deterministic historical-market research project.

- **Research engine:** configurable strategy simulation, transaction costs, causal technical features, and rule-based market regimes.
- **Decision workflow:** typed Technical, Regime, Strategy, Risk, Critic, and Memory records with machine-readable reason codes.
- **Research validation:** chronological multi-asset evaluation, walk-forward splits, leakage checks, parameter sensitivity, bootstrap intervals, ablation, benchmarks, and a transparent robustness score.
- **Product surface:** FastAPI/OpenAPI, typed Next.js client, responsive research pages, legacy Streamlit debugging view, CLI, SQLite persistence, and production CORS/deployment wiring.
- **Engineering practice:** deterministic tests, explicit dataset provenance, immutable revisions, safe SQLite maintenance, release verification, and no execution capability.

The strongest demonstration is the V1.0 reference run in [RESULTS.md](RESULTS.md), alongside its [portable artifacts](../reports/v1.0).
